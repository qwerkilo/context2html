# 可换组件消费归一化内容模型，不做逐对适配器

14 个数据型组件全部消费同一个内容模型（标题、副标题、条目、系列），每个组件读自己需要的字段、忽略其余。跨族互换（图表换卡片组）因此不需要任何映射代码。

另一条路是逐对适配器：保留每个组件自己的数据结构，跨族时写一个映射函数。14 个组件两两组合是一百多个适配器，每加一个组件都要补齐一圈。

归一化的代价是信息损失：三条系列换到卡片组只能显示一条。用两件事补偿——跨族互换前展示映射预览供确认，原始内容模型始终留在数据块里，换回原组件即完整恢复。

不属于可换集合的 17 个组件（Three.js 场景、D3 图、PPT 质感版式、装饰性 SVG）不参与这个模型，它们无法从条目与系列渲染出有意义的结果。
